Shorts Uploader

Persönliches Desktop-Tool zum automatisierten Zuschneiden und Veröffentlichen eigener Gameplay-Clips als vertikale Shorts.

Was macht das Tool?

Shorts Uploader ist ein lokal auf dem eigenen Rechner laufendes Python-Programm. Es wandelt selbst aufgenommene 16:9-Gameplay-Clips (z. B. Twitch-VODs) automatisch in vertikale 9:16-Shorts um und veröffentlicht sie anschließend auf dem eigenen TikTok-, YouTube- und Instagram-Konto. Es gibt kein öffentliches Angebot, keine Registrierung und keine Nutzer außer dem Entwickler selbst.

Funktionen

  • Automatischer Zuschnitt von 16:9-Gameplay-Aufnahmen auf das 9:16 Shorts-Format (Facecam-Overlay oder unscharfer Hintergrund)
  • Automatisch erzeugte Titel-Karten und wählbare Titelposition
  • Automatische Untertitel per lokaler Spracherkennung (kein Cloud-Dienst)
  • Web-Oberfläche zur Sichtung und Freigabe jedes Clips vor der Veröffentlichung
  • Veröffentlichung auf dem eigenen TikTok-Konto über die TikTok Content Posting API (Login Kit zur Authentifizierung des Kontoinhabers)

Wie die TikTok-Integration funktioniert

Der Kontoinhaber meldet sich einmalig über TikTok Login Kit (OAuth 2.0) an, um das Tool für das eigene Konto zu autorisieren. Danach lädt das Tool bereits fertig gerenderte Video-Dateien direkt vom lokalen Rechner über die Content Posting API (video.publish) auf das eigene Profil hoch. Es werden keine Inhalte oder Zugangsdaten Dritter verarbeitet.
